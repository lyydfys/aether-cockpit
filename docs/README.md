## 文档约定

- 命令应明确适用平台，并在改动后验证。
- 不记录真实账号、令牌、密钥、完整本机配置、可复用会话或原始个人数据。
- 截图、日志、测试输出和状态报告在进入版本控制前必须做隐私检查。
- 版本化功能说明以当前代码、自动化测试和 [更新日志](../CHANGELOG.md) 为依据；历史记录不代表上游服务持续兼容。
